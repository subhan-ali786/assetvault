# AssetVault - High-Speed 4K Digital Assets Platform

### Features Built-in:
1. **Live Search Engine:** Instant client-side indexing with tag matching and category filters.
2. **Monetized Ad Unlocker Modal:** 5-Second countdown with dual ad slot containers (AdSense ready).
3. **Recommendation Engine:** Automatically showcases similar category items on download pages.
4. **Dark Cyberpunk UI:** Modern glassmorphism, responsive grid, dynamic hover glows.

### Deployment Instructions (GitHub Pages):
1. Create a GitHub repo named `assetvault`.
2. Upload `index.html`, `download.html`, `style.css`, and `assets.json` to the root folder.
3. Go to Repo **Settings** -> **Pages** -> Select `main` branch -> **Save**.
4. Website will be live at: `https://<username>.github.io/assetvault/`
